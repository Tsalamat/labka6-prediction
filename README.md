# Practice 6 — прогнозирование зарплаты по описанию вакансии

Выполнены все пункты исходной лабораторной: загрузка и просмотр данных, гистограмма зарплат, разбиение train/test, TF-IDF с `min_df=5, max_df=1.0, ngram_range=(1,1)`, Ridge с `alpha=1.1`, R², предсказания для director/manager/data scientist и максимальный положительный вес признака.

## Запуск без venv

Используйте ваше существующее окружение с пакетами из `requirements.txt`.

```bash
python practice_6_completed.py
```

Либо откройте `Practice_6_completed.ipynb` в Colab/Jupyter и запустите ячейки по порядку.

Для первого запуска потребуется интернет, чтобы скачать оригинальный `salary_data_cleaned.csv` с GitHub. Если интернета нет, положите этот CSV в папку рядом со скриптом/ноутбуком. Скрипт создаёт `salary_distribution.png`, `prediction_scatter.png`, `answers.csv` в текущей рабочей папке.

**Важно:** в этой среде внешний CSV недоступен из-за сетевого ограничения, поэтому результаты не вычислялись и не подставлялись вымышленные значения. При запуске с доступным CSV выводятся все точные ответы.
